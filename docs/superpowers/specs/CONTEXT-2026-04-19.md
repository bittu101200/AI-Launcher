## Architecture Summary

### AI Subsystem (all new, Phase 1 complete)

**Core types** (`ai/`):
- `AIProvider.java` — Interface: `complete()`, `providerId()`, `supportsToolUse()`, `supportsStreaming()`
- `AICallback.java` — `onToken()`, `onResponse()`, `onStateChange()`
- `AIRequest.java` — Builder pattern: requestId, userMessage, systemPrompt, history, tools, maxTokens
- `AIRequestState.java` — Enum: IDLE, THINKING, STREAMING, EXECUTING_TOOLS, FOLLOWUP, COMPLETED, FAILED, TIMED_OUT_CONNECT, TIMED_OUT_INACTIVITY, CANCELLED
- `AIResponse.java` — Type enum (TEXT, ERROR, TOOL_USE), text/errorMessage/requestId fields
- `ConversationTurn.java` — Role enum (USER, ASSISTANT, SYSTEM, TOOL), content field
- `Tool.java` — name, description, inputSchema, riskClass
- `ToolCall.java` — toolName, arguments, callId
- `ToolResult.java` — callId, output, isError
- `ToolRiskClass.java` — Enum: STATELESS, STATE_CHANGING, DESTRUCTIVE
- `AISubsystem.java` — Singleton facade: submit(), cancel(), confirmCurrentTool(), declineCurrentTool()
- `RequestManager.java` — State machine wrapping AIProvider.complete(), suppresses stale callbacks
- `ConversationManager.java` — Modes: STATELESS, SESSION, PERSISTENT; compaction trigger at configurable threshold
- `CompactionEngine.java` — Generates compaction prompt preserving singleton facts
- `ToolRegistry.java` — 3-tier storage (stateless/state-changing/destructive), compressed mode serialization
- `AppCapabilityScanner.java` — Scans installed apps, produces Tool entries; PendingIntegration gate for confirm flow

**Platform layer** (`ai/platform/`):
- `LauncherIndex.java` — Enumerates installed apps, provides local retrieval data
- `JourneyManager.java` — Monitors notification+app usage patterns for context awareness

**Providers** (`ai/providers/`):
- `MockProvider.java` — Returns placeholder text, used when no real provider configured
- `ClaudeProvider.java` — Anthropic Messages API (`x-api-key` header), default model `claude-haiku-4-5-20251001`
- `OpenAIProvider.java` — OpenAI-compatible `/v1/chat/completions` endpoint, configurable base_url and model. **Also used for Gemini and Ollama.**

**Commands** (`commands/main/raw/`):
- `ai.java` — `ai <query>` sends query to AI, displays response async
- `compact.java` — Triggers conversation compaction manually
- `pin.java` — Pins latest assistant turn to persistent memory
- `clearhistory.java` — Clears conversation history
- `cleararchive.java` — Clears pinned archives

**Settings** (`managers/xml/options/Ai.java`):
- `enabled` (bool), `provider` (text: claude/openai/ollama/gemini/mock), `api_key` (text), `base_url` (text), `model` (text), `always_on_fallback` (bool), `memory_mode` (text: stateless/session/persistent), `history_token_cap` (int, default 4000), `compact_threshold` (int, default 80), `connect_timeout_ms` (int), `inactivity_timeout_ms` (int), `max_tokens` (int, default 2048), `confirm_state_changing` (bool)

### Provider Configuration

Provider is selected via `ai.xml` on device:
```xml
<provider value="gemini"/>  <!-- or claude, openai, ollama, mock -->
<api_key value="AIza..."/> <!-- provider-specific -->
<base_url value=""/>        <!-- custom endpoint (openai/ollama only; gemini uses hardcoded URL) -->
<model value="gemini-2.0-flash"/>  <!-- model override; empty = provider default -->
```

**Gemini**: Uses `OpenAIProvider` with `https://generativelanguage.googleapis.com/v1beta/openai` as base URL. Default model `gemini-2.0-flash`. Requires Google AI Studio API key.

**OpenAI**: Uses `OpenAIProvider` with `https://api.openai.com` as base URL. Default model `gpt-4o-mini`. Requires OpenAI API key.

**Ollama**: Uses `OpenAIProvider` with `http://localhost:11434` as base URL (configured via `base_url` in ai.xml). No API key needed.

**Claude**: Uses `ClaudeProvider` with Anthropic Messages API. Default model `claude-haiku-4-5-20251001`. Requires Anthropic API key.

### Debug Logging Tags

- **AI_INIT** — Provider initialization: which provider, key prefix, model
- **AI_CMD** — Command execution: query, state changes, responses
- **OpenAIProvider** — Network requests: endpoint, model, response codes/bodies

Filter with: `adb logcat -s "AI_INIT:*" "AI_CMD:*" "OpenAIProvider:*"`

## Known Issues & Notes

1. **Gemini tool_use responses**: `gemini-2.0-flash` sometimes returns `\`\`\`tool_code` blocks instead of direct text answers. This is a model behavior, not a bug. Consider adjusting the system prompt to discourage tool use when tools aren't configured.

2. **Response on background thread**: `OpenAIProvider` uses OkHttp's `enqueue()`, so `onResponse`/`onFailure` run on OkHttp's background thread. `Tuils.sendOutput()` handles this correctly (it posts to the UI thread internally).

3. **Cancel race fix**: Previously, empty input after an AI command would trigger `MainManager.onCommand("")`, which would cancel the in-flight request. Fixed to only cancel on explicit `stop`/`cancel` input.

4. **Debug signing**: Debug builds now use Android's auto-generated debug keystore. Release builds still require `release.jks` via `local.properties`.

5. **Three pre-existing deprecation warnings** in the codebase (not from our changes).

6. **Java 8 source level** throughout (no Kotlin).
